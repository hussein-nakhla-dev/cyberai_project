# EVAS-2026

منصة Streamlit لتقييم الأمان واستخبارات التهديدات، ثنائية اللغة (عربي/English)، مع تقارير PDF وHTML وJSON.

## التشغيل
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
زر **عرض تقرير تجريبي** في الشريط الجانبي يعرض الواجهة والتقارير ببيانات وهمية دون أي فحص.

## تقرير PDF بالعربية
يحتاج ثلاثة أشياء: `arabic-reshaper` و`python-bidi` (موجودتان في requirements.txt)، وخطاً عربياً.
ضع ملف خط مثل `Amiri-Regular.ttf` أو `NotoNaskhArabic-Regular.ttf` (ومعه نسخة Bold إن وُجدت) داخل `assets/fonts/`.
إن لم يتوفر شيء منها يُنشأ التقرير بالإنجليزية وتظهر رسالة تنبيه.

## مفاتيح الاستخبارات (اختياري)
انسخ `.streamlit/secrets.toml.example` إلى `.streamlit/secrets.toml` وأضف مفاتيح VirusTotal وAbuseIPDB.
Shodan InternetDB يعمل بدون مفتاح. بدون المفتاح تظهر الحالة «غير مُفعَّل» ولا تُختلق نتائج.

## الهيكل
| المسار | الدور |
|---|---|
| `app.py` | واجهة Streamlit |
| `evas/security.py` | التحقق من الهدف وحماية SSRF وطلبات HTTP الآمنة |
| `evas/scanners/` | الفحوصات: HTTP، TLS، DNS، المنافذ، الاستخبارات |
| `evas/rules.py` | كتالوج النتائج: CWE وCVSS والنصوص ثنائية اللغة |
| `evas/cvss.py`, `evas/scoring.py` | حاسبة CVSS 3.1 ونموذج الخطورة الشفاف |
| `evas/engine.py` | تشغيل الفحوصات بالتوازي وبناء النتيجة |
| `evas/reports/` | PDF وHTML وJSON وتذكرة المعالجة |
| `tests/` | اختبارات: `python -m unittest discover -s tests` |

## ما الذي تغيّر عن النسخة القديمة
- حُذفت كل النتائج الوهمية (Threat Feeds والمنافذ الثابتة وMX) واستُبدلت باستعلامات فعلية.
- حُذف ادعاء «تعلّم آلي»؛ الدرجة نموذج شفاف موضّح في الواجهة.
- الفحص يعمل مرة واحدة عند الضغط ولا يُعاد مع كل تفاعل.
- حماية SSRF: التحقق من كل عناوين الحلّ وكل تحويل، ومنافذ محدّدة، ومنع بيانات الاعتماد في الرابط.
- منع XSS بتعقيم كل القيم، ولا يُخزَّن محتوى `.env` (أسماء المتغيرات فقط).
- إقرار تفويض إلزامي، وحدّ للمعدّل داخل الجلسة.

## قيود معروفة
- احتمال DNS rebinding بين التحقق والاتصال في طلبات HTTP؛ شغّل التطبيق في شبكة معزولة عن الموارد الداخلية.
- حدّ المعدّل على مستوى الجلسة فقط، وللنشر العام أضف حداً على مستوى البنية (reverse proxy).
- درجات CVSS من متجهات أساسية مقدَّرة لكل نوع نتيجة، وليست تقييماً لبيئتك.
